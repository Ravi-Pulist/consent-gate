# Product Management

## When to Activate
- When creating PRDs or prioritizing features

## Core Principles
### 1. PRD Structure
Problem statement, personas, requirements, success metrics, constraints, timeline.

### 2. Prioritization
MoSCoW or RICE. Document rationale.

### 3. Traceability
Stories -> requirements -> business goals.

## Red Flags
- Features without user value
- Requirements without acceptance criteria
