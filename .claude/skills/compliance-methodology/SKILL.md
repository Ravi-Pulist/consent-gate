# Compliance Methodology

## When to Activate
- When auditing compliance against regulations

## Core Principles
### 1. Control Mapping
Map every requirement to a system control. Track: implemented, partial, gap.

### 2. Risk Assessment
Severity = likelihood x impact. Prioritize by risk score.

### 3. Evidence Collection
Every control needs verifiable evidence. Automate where possible.

## Red Flags
- Regulations without control mapping
- Gaps without remediation timeline
