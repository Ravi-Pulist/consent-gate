# Research Methodology

## When to Activate
- When investigating domain standards or technologies

## Core Principles
### 1. Source Evaluation
Primary > secondary. Official docs > blogs. Recent > outdated. Cite everything.

### 2. Confidence Levels
HIGH: Multiple authoritative sources. MEDIUM: Single authoritative. LOW: Limited/conflicting.

### 3. Structured Output
Question, Sources, Findings, Confidence, Recommendations.

## Red Flags
- Claims without citations
- Single-source conclusions
