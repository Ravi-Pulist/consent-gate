# DevOps Practices

## When to Activate
- When designing CI/CD pipelines or infrastructure

## Core Principles
### 1. CI/CD
Automated build, test, deploy. Fast feedback. Immutable artifacts.

### 2. Infrastructure as Code
All infra in version control. Reproducible environments. No manual changes.

### 3. Observability
Structured logging. Metrics for SLIs. Alert on SLO violations.

## Red Flags
- Manual deployment steps
- Configuration drift
- Missing monitoring
