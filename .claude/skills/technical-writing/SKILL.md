# Technical Writing

## When to Activate
- When creating or updating documentation

## Core Principles
### 1. Audience First
Developers: code examples. Users: task-based guides. Ops: runbooks.

### 2. API Documentation
Every endpoint: method, path, parameters, examples, error codes.

### 3. Keep Current
Sync docs with code changes. Outdated docs are harmful.

## Red Flags
- No code examples
- Outdated information
- Jargon without explanation
