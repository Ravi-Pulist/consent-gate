# E-Commerce SEO & Performance

## When to Activate
- When working on e-commerce projects that involve search engine optimization, structured data markup, or Core Web Vitals improvement
- When optimizing product pages for discovery, implementing Open Graph tags, or improving page load performance

## Core Principles
### 1. Structured Data for Product Discovery
Every product page must include JSON-LD structured data (Product, Offer, Review schemas) that accurately reflects the page content. Search engines use structured data for rich results — missing or inaccurate markup means lost visibility in search results.
