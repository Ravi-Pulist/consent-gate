# SOC 2 Compliance

## When to Activate
- When working on SaaS projects that involve SOC 2 audit preparation, trust service criteria mapping, or evidence collection
- When designing controls for security, availability, processing integrity, confidentiality, or privacy

## Core Principles
### 1. Automate Evidence Collection
SOC 2 audits require continuous evidence of control effectiveness. Manual evidence collection does not scale and creates audit preparation crunches. Build automated evidence pipelines (config snapshots, access reviews, deployment logs) that run continuously, not just before audit season.
