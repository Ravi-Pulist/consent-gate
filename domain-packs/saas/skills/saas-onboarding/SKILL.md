# SaaS Onboarding Patterns

## When to Activate
- When working on SaaS projects that involve new tenant provisioning, trial-to-paid conversion, or user activation flows
- When designing self-service signup, data migration tools, or onboarding UX

## Core Principles
### 1. Fast Time-to-Value
The onboarding flow must get users to their first meaningful action as quickly as possible. Every additional step before value realization increases drop-off. Defer non-essential setup (integrations, team invites, advanced config) to post-activation.
