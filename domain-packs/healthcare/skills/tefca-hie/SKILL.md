# TEFCA & Health Information Exchange

## When to Activate
- When working on healthcare projects that involve health information exchange networks, QHIN connectivity, or TEFCA designated use cases
- When designing cross-organizational data sharing using the Trusted Exchange Framework

## Core Principles
### 1. Trust Framework Compliance
TEFCA participation requires adherence to the Common Agreement and designated use cases. Data exchange must follow the Standard Operating Procedures (SOPs) for query, message delivery, and population-level exchange. Unauthorized use cases violate the trust framework.
