# CDS Hooks

## When to Activate
- When working on healthcare projects that involve clinical decision support integration with EHR workflows
- When implementing CDS Hooks services that respond to clinical events with actionable cards

## Core Principles
### 1. Minimize Clinician Burden
CDS cards must be concise, actionable, and contextually relevant. Alert fatigue is a patient safety risk. Return only high-value recommendations and use the indicator field (info/warning/critical) accurately to reflect urgency.
