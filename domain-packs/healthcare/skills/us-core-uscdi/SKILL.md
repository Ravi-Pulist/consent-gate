# US Core & USCDI

## When to Activate
- When working on healthcare projects that involve US Core profile conformance, USCDI data class implementation, or ONC certification data requirements
- When mapping clinical data to standardized USCDI categories

## Core Principles
### 1. Must-Support Means Must Implement
US Core "must support" elements are not optional — systems must be capable of storing, returning, and processing these elements. Ignoring must-support flags will cause ONC certification failure and interoperability gaps.
