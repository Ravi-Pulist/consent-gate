# Financial Data Modeling

## When to Activate
- When working on fintech projects that involve ledger design, account structures, or transaction recording
- When implementing double-entry bookkeeping, reconciliation, or financial reporting data models

## Core Principles
### 1. Double-Entry is Non-Negotiable
Every financial transaction must have balanced debits and credits. The double-entry system is not an optional pattern — it is the foundation of financial integrity. Any ledger that allows unbalanced entries will produce irreconcilable financial statements.
